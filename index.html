Security Web App · PhishGuard AI Python & HTML/CSS/JS

URL Phishing Detector

Masalah: Tautan phishing kerap menyamarkan domain asli lewat panjang path, angka atau tanda hubung berlebih, hingga pemakaian alamat IP mentah untuk mengecoh pengguna.

Pendekatan Teknis: Membangun backend Python (ThreadingHTTPServer) dengan endpoint GET /api/health dan POST /api/predict yang terhubung ke antarmuka web PhishGuard AI (HTML, CSS, JavaScript).

Cakupan Fitur: Mengekstrak 8 fitur leksikal URL (path_length, url_length, num_dots, num_hyphens, num_digits, has_https, has_ip), pengecekan domain tepercaya, serta skor risiko dengan lexical fallback saat model Random Forest tidak dimuat.

  • Python
  • ThreadingHTTPServer
  • HTML / CSS / JS
  • REST API
  • Lexical Analysis
